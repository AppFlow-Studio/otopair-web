# Ground truth: 2024 Toyota Grand Highlander Hybrid 2.5L A25A-FXS + eCVT (US market)

**Model-year substitution note:** the request said "2023" — there is **NO MY2023 Grand Highlander**. The Grand Highlander launched as a **first-model-year 2024** vehicle (production from mid-2023). Any "2023 Grand Highlander" data emitted by the pipeline is fabricated or cross-contaminated. This sheet covers the **standard Hybrid (A25A-FXS 2.5L + eCVT, 245 hp system)** — NOT the Hybrid MAX (T24A-FTS 2.4L turbo hybrid + 6AT); Hybrid MAX divergent values are in the sidebar because both share one Warranty & Maintenance Guide and are the #1 contamination source.

## Adversarial traps (wrong-answer decoys the pipeline may ingest)

1. **MY2023 does not exist.** First model year is 2024. A "2023 Grand Highlander" record can only be a fabrication or a regular-Highlander (XU70) bleed-through.
2. **0W-8 looks wrong but is CORRECT — do not "fix" it.** Every other US A25A-FXS application (Camry/RAV4/Highlander/Sienna/Venza hybrid) specifies 0W-16, so a consensus-driven pipeline will "correct" the Grand Highlander to 0W-16. The OM is verbatim: JASO GLV-1 0W-8 recommended, 0W-16 permitted fallback ONLY with mandatory return to 0W-8 at the next change. "0W-16 recommended" (unqualified) = FAIL; so is "0W-20" (that's Hybrid MAX/gas-2.4T bleed).
3. **Engine code alone does NOT determine the oil filter.** Same A25A-FXS engine, different filter format by platform: GH Hybrid = **spin-on 90915-YZZN1**; Camry/RAV4/Highlander/Sienna hybrid A25A-FXS = **cartridge 04152-YZZA1**. A "04152-YZZA1 cartridge" answer for the GH = same-engine-different-vehicle contamination (the exact P0 class flagged in batch-10).
4. **Hybrid MAX contamination (see sidebar):** 0W-20/5.6 qt oil, NGK plugs at 40k, 6AT with 6.8 qt WS, e-Transaxle Fluid TE rear axle, intercooler coolant loop, drive-belt and vacuum-pump line items. Any of these on a 2.5L Hybrid record = FAIL. Reverse direction too: quoting 120k plugs or eCVT for a Hybrid MAX = FAIL.
5. **Regular Highlander (XU70) decoys:** Highlander Hybrid 2.5 = 0W-16 + cartridge filter; gas Highlander/GH 2.4T = 0W-20, no inverter coolant, no HV items. Note the gas 2.4T Grand Highlander ALSO replaces plugs every 40k (its own 2024 WMG, verified) — so "40k plugs" is a T24A-FTS signature (gas or Hybrid MAX), never an A25A-FXS one.
6. **eCVT "transmission flush/service" upsells:** fluid is ordinary Toyota ATF WS (4.6 qt reference), but the WMG schedules NO replacement at any mileage under normal driving — leak inspection only; the only "Replace automatic transmission fluid" line for this vehicle is the 120k **towing/heavy-load special condition**. Also reject "CVT belt/pulley" language — the eCVT is a power-split planetary with no belt, and "Toyota CVT Fluid TC/FE" (belt-CVT fluid, e.g. Corolla) = wrong fluid family.
7. **Coolant half-truths:** "coolant change at 100k then 50k" is correct ONLY for the engine loop; the inverter (PCU) loop's first change is **150k**. Capacities must be per-loop (10.8 + 2.1 qt); quoting a single ~7 qt Camry-style figure = wrong vehicle.
8. **Hybrid battery chemistry:** NiMH (216 cells, 259.2 V), not Li-ion — despite most 2023+ Toyota hybrids (Prius, Camry XV80, Crown lower trims in some markets) moving to Li-ion. Any "scheduled hybrid battery replacement" claim = FAIL; the only scheduled item is the cooling intake filter (inspect 5k/clean 20k).
9. **Legitimate crosses (do NOT flag):** spark plug 90919-01289 / DENSO FC16HR-Q8 genuinely shared with Camry/RAV4 A25A engines (gap 0.8 mm, 120k on this vehicle); oil filter 90915-YZZN1 genuinely shared with many spin-on Toyotas (Tacoma, Corolla, 2.4T); air filter 17801-F0080 genuinely shared with 2023+ Crown. Near-miss decoys that do NOT cross: 17801-F0050/17801-25020 (Camry), 87139-58010-as-default (premium charcoal alternate; standard is 87139-0R030/YZZ83).
10. **Look-wrong-but-correct values:** 12V battery in the **luggage compartment** (not underhood, unlike RAV4/Highlander hybrids); cabin+engine air filters on a 30k cadence (not Camry's 10k cabin cadence); brake fluid spec allows DOT 3 **or** DOT 4; "EFI Tank Additive" at every service is Hawaii/Puerto Rico only — not a mainland service item.
