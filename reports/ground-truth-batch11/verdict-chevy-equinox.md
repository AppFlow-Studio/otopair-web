## DEFECTS

**P1-a. Transmission fluid "GM CVT Fluid (green)" on a 6T45 geared 6-speed automatic** (GT 3b, trap 3). Correct spec: **DEXRON-VI** (web-verified: parts.chevrolet.com ACDelco DEXRON-VI listing, AutoZone/carfluidguide Equinox 6T45 pages). This is the INVERSE of the batch-11 Rogue defect — there a CVT got stepped-ATF, here a stepped automatic got CVT fluid — and it is internally contradictory with the run's own `speeds: 6, type: "Automatic"` (both from vPIC, both correct). A CVT-fluid fill in a 6T45 is a wrong-fluid-class service recommendation (frictional properties differ; damaging). Source is 2025 4th-gen dealer/maintenance content (the new Equinox is CVT-FWD/8AT-AWD). **Round-10 fix: mirror the round-9 `transFluidSpecReconcile` — it only covers CVT-type + stepped-spec; the automatic-type + CVT-spec direction has NO gate, which is exactly what shipped here.** Note atf_fluid part is null, so no part-level corroboration existed to catch it either.

**P1-b. Engine code LSD — identity poisoned by vPIC itself** (GT row 1, trap 3). vPIC DecodeVin returns EngineModel "LSD" for this 2024 VIN (re-verified live during audit); GT: 2024 = LYX (TechLink oil chart row is engine-keyed "1.5L L4 ... LYX"), LSD = 2025 RPO. The pipeline accepted the upstream field verbatim into `config_key` and `engine.code` with no model-year/RPO validity check. This is a NEW defect class: prior batches' engine-code errors came from web extraction or decode inference; this one is a trusted-decoder data error propagated untouched. Consequence: every "LSD"-anchored search pulls 4th-gen content — the most plausible root cause of P1-a and P2-a. Fix: RPO-validity table (RPO x model-year ranges) gating decoder output, falling back to year+model+displacement inference (which yields LYX uniquely — 2024 has exactly one engine).

**P1-c. Oil capacity 5.3 qt on a FWD VIN** (GT 2b, trap 5). GT verbatim from GM TechLink: FWD LYX = 4.0 L/4.2 qt, AWD LYX = 5.0 L/5.3 qt. This VIN decodes FWD (vPIC, and the run itself stored `drivetrain: "FWD"`), so 5.3 is the wrong-drivetrain value — a 1.1-qt overfill spec sold at engine level. The capacity picker demonstrably ignored the run's own drivetrain field; GT trap 5 warned this dual-capacity engine punishes any single-value answer that isn't drivetrain-keyed. (Contrast: this is NOT the look-wrong-but-correct case — that would be 5.3 on an AWD build.)

**P1-d. Battery "48AGM"** (GT row 9, trap 7). Group 48/H6 is the other-GM-platform decoy; 3rd-gen Equinox = **Group 47 (H5)** per GM's own accessory listing. Single source (oilchangediy.com — a mid-tier aggregator), and priced from parts.chevrolet.com $320.41 plus corvetteforum.com $152 (a forum as a price source — hygiene). Wrong group = wrong tray/hold-down fit. Almost certainly one of the two `part_pattern_suspect:Chevrolet` flags ("48AGM" is not a GM PN pattern) — flagged but shipped anyway (flag-only gate).

**P1-e. Engine air filter 84588699 — unverifiable part number** (GT 6a).
